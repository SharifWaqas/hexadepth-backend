The engineering distinction

Region coordinates and early image previews use lossy or abstract representations. They are intentionally smaller than the original. The exact-file option still sends all required bytes and verifies the original with SHA-256.

Model status

The provided package does not include trained sonar detector weights. This prototype can select regions using untrained OpenCV saliency and will use an optional trained detector if its weights are installed. It never interprets saliency as certainty.
