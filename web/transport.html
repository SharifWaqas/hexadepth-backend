Built for constrained links

What this prototype demonstrates

Preserve the data first. Lossless image mode works for any decodable sonar image, even if the AI detector has never seen its object. PNG/JPEG files may already be compressed, so the transferred file can remain large.

Transport, not sonar imaging. Sonar collects the image; a separate compatible acoustic data modem would carry the packets. This prototype simulates 64-byte framing, link airtime, packet CRC and file SHA-256, not an actual underwater transmission.

Parallel links have a cost. More links help only when independent acoustic bandwidth, hardware and interference controls are available. Lossless file delivery is not instantaneous; acoustic links are bandwidth-limited.

Bundled real sonar samples: Santos et al. (2024), MILCO side-scan dataset, dataset and attribution (CC BY 4.0). This is a research and hackathon prototype, not a validated underwater communications system.
